# Architecture decision records (ADR)

← Back to the [maintainer documents](../README.md)

An ADR records **the context and the reasons at the time a decision was made**. It is not rewritten as the
implementation evolves: when a decision is overturned, it is marked "Superseded" and points to the new ADR.
